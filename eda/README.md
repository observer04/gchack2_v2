# EDA Assets

This folder contains all exploratory data analysis (EDA) artifacts for the glacier segmentation dataset.

## Contents

- 01_comprehensive_eda.ipynb — End-to-end EDA notebook with dataset structure, indices, texture, PCA, and spatial autocorrelation.
- preliminary_eda.ipynb — Early/rough EDA draft.
- EDA_NOTEBOOK_ADDITIONS.md — Notes and add-ons planned/implemented for the EDA.
- NOTEBOOK_FIXED.md — Record of fixes and refactors applied to the notebooks.
- data_insights.md — Concise, data-backed summary of findings to inform modeling.
- *.png — Plots and figures generated by the notebooks:
  - class_distribution_analysis.png
  - spectral_signatures.png
  - band_correlation.png
  - boundary_analysis.png
  - multiband_samples.png
  - spectral_indices_analysis.png
  - glcm_texture_analysis.png
  - pca_analysis.png
  - spatial_autocorrelation_analysis.png

## Notes

- If any markdown or notebook previously referenced images at the repository root, update those paths to prefix with `eda/`.
- Notebooks assume `Train/` lives at the project root; no changes needed to run after this move.
- Python 3.12 environment is available under `gc/`. If running elsewhere, ensure required packages from `Requirements.txt` are installed.
